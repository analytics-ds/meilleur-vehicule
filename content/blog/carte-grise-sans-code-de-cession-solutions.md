> **En bref**
> 1. L'absence de code de cession ne bloque pas l'immatriculation : **trois voies** existent, dont **deux** sans code.
> 2. Sur le site de l'État, il faut alors le **numéro de formule** et la **date d'émission** de la carte grise barrée. Sans code de cession, la fourniture de documents y est obligatoire et les délais de traitement se rallongent considérablement.
> 3. Un véhicule acheté à un professionnel ne génère **en principe pas** de code de cession : c'est normal, pas une erreur.
> 4. Chez un professionnel habilité comme cartegrise.com (habilité depuis **2009**, plus d'**1 million de dossiers** traités), le code n'est pas demandé.

Une Clio achetée à un particulier trouvé en ligne, un rendez-vous sur un parking, la carte grise barrée et le certificat de cession remis en main propre. Le vendeur devait envoyer le code de cession « le soir même ». Une semaine plus tard, il ne répond plus au téléphone, et la démarche en ligne s'arrête à l'étape du code.

Le code de cession simplifie la démarche, mais il n'est pas indispensable. Selon la situation, la voie officielle reste ouverte avec d'autres informations, ou un professionnel habilité prend le relais. Voici quelle solution choisir, cas par cas, sachant que le délai d'un mois après l'achat continue de courir pendant ce temps.

## Quelle solution selon votre situation

|---|---|---|---|

## Le vendeur n'a pas déclaré la vente

C'est le cas le plus fréquent. Le vendeur doit déclarer la cession dans les 15 jours qui suivent la vente, en application de l'article R322-4 du Code de la route. C'est cette déclaration, faite en ligne, qui produit le code de cession à transmettre à l'acheteur. Tant qu'elle n'est pas faite, il n'y a pas de code.

Deux options s'ouvrent à l'acheteur.

- **Relancer le vendeur.** Un message écrit, qui rappelle l'obligation et le délai de 15 jours, suffit souvent. Le vendeur a lui-même intérêt à déclarer la vente : tant qu'elle ne l'est pas, les avis de contravention liés au véhicule continuent de lui être adressés.
- **Avancer sans lui.** Sur le site de l'État, la demande reste possible sans code, avec le numéro de formule et la date d'émission de la carte grise barrée. Chez un professionnel habilité, le code n'est pas demandé.

Le choix dépend du temps disponible. Si le vendeur répond dans la journée, le code règle tout. S'il reste silencieux, attendre fait perdre des jours sur le délai d'un mois. Les documents que le vendeur doit remettre le jour de la vente sont rappelés dans notre article sur les [documents obligatoires pour vendre sa voiture](/blog/vendre-voiture-particulier-documents-obligatoires/).

## Le code a été perdu ou a expiré

La réponse officielle de France Titres-ANTS du 2 octobre 2023, publiée sur la plateforme Services Publics+, fixe trois points : le code de cession compte 5 chiffres, il reste valable 15 jours, et il ne peut pas être récupéré une fois perdu.

Un code noté sur un papier égaré, ou transmis trop tard, ne sert donc plus. Le vendeur ne peut pas le faire réapparaître, et l'acheteur ne peut pas le demander à l'ANTS.

La même réponse officielle indique la voie de secours : l'acheteur peut faire sa demande sans code sur le site de l'État, en saisissant le numéro de formule et la date d'émission de la carte grise barrée remise par le vendeur. Ces deux informations figurent sur le certificat lui-même. Cette voie a un coût en temps : sans code de cession, la fourniture de documents est obligatoire sur le site de l'ANTS, et les délais de traitement se rallongent considérablement.

Chez un professionnel habilité, le code perdu ou expiré ne change rien : il saisit le dossier directement dans le système d'immatriculation des véhicules, sans passer par le code. [cartegrise.com](https://www.cartegrise.com) détaille ce cas sur sa page pour [immatriculer sans code de cession](https://www.cartegrise.com/code-de-cession).

## Achat chez un professionnel : pourquoi il n'y a pas de code

Acheter une voiture chez un garage ou un concessionnaire surprend parfois l'acheteur habitué aux ventes entre particuliers : aucun code de cession n'est remis. Ce n'est pas une erreur.

Le code de cession est produit par la déclaration de vente en ligne d'un particulier. Un professionnel de l'automobile suit son propre circuit, et ne génère donc en principe pas de code. Beaucoup de professionnels habilités prennent eux-mêmes en charge la carte grise de l'acheteur au moment de la livraison, parfois contre une prestation facturée.

Deux vérifications suffisent au moment de l'achat : savoir si le garage fait la démarche, et, s'il ne la fait pas, obtenir les documents de vente nécessaires pour la faire soi-même. Notre checklist pour [acheter une voiture d'occasion](/blog/acheter-voiture-occasion-checklist/) reprend les pièces à récupérer, que le vendeur soit un particulier ou un professionnel.

## La carte grise barrée est incomplète ou égarée

La carte grise barrée est la pièce centrale du dossier. Le vendeur doit la remettre en entier, barrée avec la mention « Vendu le » suivie de la date et de sa signature. Sur une carte grise récente, le coupon détachable permet à l'acheteur de circuler en France pendant 1 mois, le temps d'obtenir la nouvelle carte à son nom.

Quand elle manque ou qu'elle est incomplète, la voie officielle sans code devient difficile : c'est sur ce document que se lisent le numéro de formule et la date d'émission. Deux réflexes à avoir.

- **Recontacter le vendeur.** Il peut disposer d'une photo ou d'une copie de la carte grise, qui permet au moins de retrouver ces informations.
- **Confier le dossier à un professionnel habilité.** Il examine les pièces disponibles et indique celles qui restent à fournir avant d'enregistrer la demande.

Ce cas illustre le principal intérêt d'un professionnel : le dossier est vérifié avant d'être déposé, ce qui évite un refus après coup. Chez cartegrise.com, les frais d'un changement de titulaire vont de 44,90 à 99,90 € selon le montant de la taxe régionale, en plus des taxes, identiques sur toutes les voies.

## Quel site choisir pour immatriculer sans code

Plusieurs professionnels habilités par le Ministère de l'Intérieur publient une page consacrée au cas sans code de cession. Quelques repères relevés le 30 septembre 2026 :

- **cartegrise.com** : habilité depuis 2009 (habilitation Préfecture n° 9744, agrément Trésor public n° 14871), code de cession non exigé, traitement et certificat provisoire annoncés sous 12 à 24 h après réception du dossier complet, suivi du dossier en temps réel dans l'espace personnel.
- **cartegriseminute.fr** : habilitation n° 15119, agrément n° 21599, traitement annoncé en 24 h maximum, frais à partir de 49,90 € selon la taxe régionale.
- **guichetcartegrise.com** : habilitation n° 212900, agrément n° 52480, analyse des pièces annoncée en 24 h, frais de 59 à 149 € selon la taxe régionale.
- **eplaque.fr** : habilitation n° 18621, agrément n° 26579, pas besoin du code de cession d'après le site, frais à partir de 29,90 €.

La voie officielle, elle, reste gratuite hors taxes. cartegrise.com est un prestataire habilité, distinct de l'ANTS.
