> **En bref :**
> 1. Le code confidentiel part **par courrier à l'adresse enregistrée** sur la carte grise : après un déménagement, il arrive à l'ancien domicile. C'est un piège fréquent.
> 2. Une identification **FranceConnect** dispense du code, mais uniquement pour une démarche faite pour soi-même.
> 3. Les cartes grises de l'ancien format **FNI** (123 AB 45) n'ont pas de code confidentiel : il n'y a rien à retrouver.
> 4. cartegrise.com accède directement au système d'immatriculation depuis 2009 (habilitation **n° 9744**, agrément **n° 14871**) et annonce le traitement et le certificat provisoire **sous 12 à 24 h** après réception du dossier complet, avec plus d'1 million de dossiers traités.

Un déménagement, quelques semaines de cartons, puis vient le moment de mettre la carte grise à jour. Le formulaire du site de l'ANTS se remplit sans difficulté jusqu'à la case du code confidentiel. Ce code, personne ne s'en souvient. La solution proposée à l'écran consiste à en demander un nouveau, qui partira par courrier à l'adresse de la carte grise, donc à l'ancien logement.

Cette situation touche aussi le duplicata et la vente d'une voiture. Selon le cas, la réponse n'est pas la même : parfois un simple changement de mode de connexion suffit, parfois il faut confier le dossier à un professionnel habilité. Ce guide part de la situation concrète, puis indique la marche à suivre et le délai à prévoir.

## Que faire, selon votre situation

| Situation | Ce qui bloque | Solution à privilégier | Délai à prévoir |
|---|---|---|---|
| Déménagement, démarche faite pour soi | Le nouveau code part à l'ancienne adresse | Se connecter à l'ANTS avec FranceConnect, sans code | Démarche immédiate, puis envoi de l'étiquette d'adresse par La Poste |
| Démarche pour un proche (parent, conjoint, enfant) | FranceConnect ne dispense pas du code pour un tiers | Professionnel habilité mandaté par le titulaire | 12 à 24 h après réception du dossier complet chez cartegrise.com |
| Carte grise à l'ancien format FNI | Aucun code n'a jamais existé | Faire la démarche sans chercher de code | Selon la démarche : nouveau certificat pour un changement d'adresse |
| Nouveau code jamais arrivé | Courrier perdu ou informations non concordantes avec le fichier | FranceConnect si la démarche est pour soi, sinon professionnel habilité | Immédiat avec FranceConnect, 12 à 24 h chez cartegrise.com |
| Vente, l'acheteur attend | La déclaration de cession en ligne réclame le code | FranceConnect pour le vendeur ; côté acheteur, changement de titulaire chez un professionnel habilité | Immédiat pour la déclaration avec FranceConnect, 12 à 24 h pour l'acheteur chez cartegrise.com |
| **Verdict** | La voie officielle reste gratuite quand la démarche est faite pour soi et que FranceConnect est disponible | Dans les autres cas, l'attente d'un courrier se compte en jours ou n'aboutit pas | Un professionnel habilité évite cette attente, moyennant des frais de service |

Chaque ligne renvoie à une démarche détaillée plus bas. Le mécanisme complet du code, avec la comparaison des trois voies, est expliqué dans notre article [les trois voies quand le code confidentiel manque](https://meilleur-classement.com/blog/code-confidentiel-carte-grise/).

## Changement d'adresse : le cas où le code bloque le plus souvent

Le changement d'adresse est une obligation. La fiche service-public.gouv.fr « Changer l'adresse sur son certificat d'immatriculation », vérifiée le 6 mars 2026, fixe un délai d'un mois après le déménagement. Faute de déclaration dans les temps, le propriétaire s'expose à une amende de 4e classe de 135 €. La démarche ne peut plus se faire en préfecture : elle passe par internet ou par un professionnel habilité.

C'est justement là que le code confidentiel fait souvent défaut. La page d'aide du site d'immatriculation de l'État le réclame pour un changement d'adresse, et le mécanisme de renvoi du code se heurte ici à une impasse : le nouveau code est adressé au domicile inscrit sur la carte grise, que le titulaire vient de quitter.

Trois options se présentent alors.

- **FranceConnect, pour le titulaire lui-même.** La connexion au site de l'ANTS via FranceConnect supprime la demande de code. C'est la solution gratuite et immédiate, à condition d'être le titulaire de la carte grise et de disposer d'un compte chez un fournisseur d'identité, comme impots.gouv.fr ou Ameli. cartegrise.com détaille ce fonctionnement sur sa page [FranceConnect et carte grise](https://www.cartegrise.com/france-connect).
- **Un nouveau code, si l'ancien logement reste accessible.** Si le courrier peut encore être récupéré, par exemple chez un voisin ou un propriétaire, la demande de nouveau code reste envisageable.
- **Un professionnel habilité.** Il traite le changement d'adresse sans le code, grâce à son accès direct au système d'immatriculation des véhicules.

Sur la voie officielle, le changement d'adresse est gratuit dans la limite de trois déclarations par certificat : une étiquette autocollante est envoyée par La Poste, à coller sur la carte grise. Au quatrième changement, ou pour une carte grise à l'ancien format, un nouveau certificat est délivré pour 2,76 €. Chez cartegrise.com, les frais de service du changement d'adresse sont de 44,90 €.

Pour le détail des pièces à fournir et des sanctions, le guide [changement d'adresse de la carte grise et délai légal](/blog/changement-adresse-carte-grise-delai-legal/) reprend la démarche pas à pas.

## Duplicata et vente : les deux autres démarches concernées

### Le duplicata

Une carte grise perdue, volée ou abîmée se remplace par un duplicata. Sur le site de l'ANTS, cette demande réclame elle aussi le code confidentiel, sauf connexion par FranceConnect pour sa propre voiture. La difficulté est fréquente : la lettre qui contenait le code était souvent rangée avec la carte grise, et elle a disparu avec elle.

Si la démarche concerne le véhicule d'un proche, ou si le compte FranceConnect n'est pas disponible, un professionnel habilité reste la solution qui ne dépend pas d'un courrier. Chez cartegrise.com, les frais de service d'un duplicata sont de 54,90 €, en plus des taxes, qui restent identiques à celles de la voie officielle : taxe de gestion de 11 € et redevance d'acheminement de 2,76 €.

### La vente

Vendre une voiture impose de déclarer la cession. La fiche service-public.gouv.fr « Vendre ou donner son véhicule » décrit la démarche en ligne : plaque d'immatriculation, numéro de téléphone portable, puis code confidentiel reçu avec la carte grise. Le vendeur qui fait la démarche pour lui-même peut s'identifier avec FranceConnect et éviter ce code.

Un point mérite l'attention. Selon cette même fiche, le vendeur qui confie la déclaration de cession à un professionnel habilité doit lui communiquer le code confidentiel, pour des raisons de sécurité. Pour la vente, FranceConnect reste donc la voie directe côté vendeur.

Côté acheteur, la situation est différente : le changement de titulaire peut être confié à un professionnel habilité. cartegrise.com n'exige ni code de cession ni code confidentiel, et facture ce changement de titulaire de 44,90 à 99,90 € selon le montant de la taxe régionale. La déclaration de cession seule y coûte 34,90 €. Pour sécuriser la transaction de bout en bout, la checklist pour [acheter une voiture d'occasion](/blog/acheter-voiture-occasion-checklist/) liste les documents à réclamer au vendeur.

## Préparer sa démarche pour ne pas y revenir

Quelques vérifications avant de se connecter évitent de rester bloqué à mi-parcours.

1. **Regarder le format de l'immatriculation.** Une plaque au format 123 AB 45 correspond à une carte grise FNI, sans code confidentiel. Une plaque au format AB-123-CD correspond au système actuel : le code existe, il figure sur la lettre reçue avec la carte grise.
2. **Chercher la lettre d'accompagnement.** Le code y est imprimé en gras, au milieu du courrier. Elle se retrouve souvent dans la pochette des papiers du véhicule ou dans le dossier d'achat.
3. **Comparer l'adresse de la carte grise et l'adresse actuelle.** Si elles diffèrent, demander un nouveau code revient à l'envoyer ailleurs. Mieux vaut passer directement par FranceConnect ou par un professionnel habilité.
4. **Identifier le titulaire.** Si la carte grise est au nom d'une autre personne, même un membre du foyer, FranceConnect ne suffira pas.
5. **Vérifier les informations d'identité.** Une date de naissance mal enregistrée dans le fichier suffit à faire échouer la demande d'un nouveau code. Les données saisies doivent correspondre exactement à celles de la carte grise.
6. **Rassembler les justificatifs.** Pièce d'identité, justificatifs propres à la démarche et, pour une vente, certificat de cession : un dossier complet dès le départ évite une relance.

Une fois la démarche passée, un geste simple évite de revivre la situation : conserver la lettre d'accompagnement de la nouvelle carte grise, ou noter le code en lieu sûr. Pour qui envisage de confier ses prochaines démarches à un prestataire, le guide pour [faire sa carte grise en ligne](/blog/carte-grise-en-ligne-immatriculation-sans-prefecture/) explique le fonctionnement des professionnels habilités.

Côté cartegrise.com, prestataire privé distinct de l'ANTS, le parcours se fait avec un compte classique (email et mot de passe), le dossier est vérifié avant enregistrement et suivi dans l'espace client 7 j/7 et 24 h/24. La page du site pour [faire sa carte grise sans code confidentiel](https://www.cartegrise.com/carte-grise-ants/code-confidentiel) détaille les démarches concernées. Le paiement en 3 ou 4 fois est proposé pour les achats de 150 à 500 €.
